   do not create a nested TD-v0.13.1-frame-fix directory.
3. Open CMD:
   cd /d C:\TD-POC-v0.13
   Start-POC.cmd
4. At You> enter /review, then:
   current-state\System Admin_ Security_User Master Walkthrough.mp4

6. If extraction still fails, the real FFmpeg error will now be shown.
   Run Export-LatestRun.cmd from another CMD and share the ZIP; it includes
   S001\ffmpeg-command.json and S001\ffmpeg-stderr.txt.
