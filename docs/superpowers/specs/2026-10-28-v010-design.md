# TD POC 0.10 approved design
Single-machine Windows Server 2019, Ryzen 7700, 31 GB RAM, RTX 5060 Ti 8 GB, Visual Studio 2026 and .NET 10. Codex CLI uses existing login for reasoning; Ollama qwen3-embedding:4b performs embeddings. Auto scan, manual process. No automatic deletion, no meeting-recordings subtree, no existing app process termination. SRT/video basename pairing; original source folders remain unchanged.
Three C# projects provide console UX, workflow orchestration and process integrations. A Python worker supplies document extraction, PostgreSQL persistence and embedding/search operations through JSON stdin/stdout. This avoids coupling extraction libraries to .NET and uses existing Python installation; setup creates an isolated venv. Host, not agents, owns DB credentials and validates every handoff with unchanged td-doc-review-2.0. Original 2.1 prompts retained with an explicit local-evidence adapter. Coordinator sees bounded retrieved evidence, never reviewer-only expectations. Original archives are logical labels in unchanged request contract; local mapping is explicit in run manifest. Original cases retained unmodified and local requests generated with user-selected recording/SRT.
Supported extraction: text/code/JSON/HTML/Markdown/SRT/DOCX/XLSX/XLS/CSV/PDF. Images and SNAG/legacy DOC remain inventoried NEEDS_CONVERSION, never silently complete. Videos registered pending visual review; SRT is narrated evidence. Optional ffmpeg supplies timestamped frames for scoped agent tests; missing frames force partial/blocked claims. No auto transcription.
Incremental scan hashes readable allowlisted files without DB writes; user processing registers physical identity, revisions, source identity, extractions and chunks transactionally per file. Re-run reuses same hash versions and retries failures; newest successfully processed local revision replaces older selected revision. Original Drive mappings retained separately; LOCAL_FILE constraint migration explicit, no synthetic Drive IDs.
Runs pin evidence versions; A and B receive separate bounded packets; JSON structure, identity, request preservation, cited provenance, observation coverage and human-review nonfabrication are gated. Partial passes remain partial. All derived records remain AGENT_PROPOSED. Source and derived vectors isolated by immutable profile digest. Live handoff logs and exportable raw outputs/results.
Approaches considered: C#-only parsers; C# console plus Python evidence worker (selected to cover formats with mature parsers); full agent SDK (excluded by user). No separate reasoning API. User approved layout and option A; implementation authorized in conversation.
